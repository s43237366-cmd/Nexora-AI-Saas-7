01 / QUICKSTART

Install in seconds.

Add the SDK to your existing project and initialize your first agent.

terminal
$ npm install @nexora/sdk

$ nexora init

✓ Workspace connected
✓ Repository indexed
✓ AI agent ready
02 / AGENT API

Ask the agent.

agent.ts
import { Agent } from '@nexora/sdk';

const agent = new Agent({
  model: 'nexora-pro',
  workspace: './'
});

const result = await agent.run(
  'Build a secure auth flow'
);

console.log(result.diff);
